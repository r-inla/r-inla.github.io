Support & Issues

Explore common problems and follow best practices before submitting a new issue

1. Please Update R First

Most reported issues stem from using an outdated version of R. To avoid unnecessary errors and compatibility problems, please ensure you're running the latest stable version. Download the latest version from the CRAN website.

2. Ensure INLA is Up to Date

The R-INLA package is actively maintained. To upgrade, run the following in your R console:

inla.upgrade() # For the stable version inla.upgrade(testing = TRUE) # For the testing version

3. Create a New Issue

If the problem persists, open a new issue on the GitHub Issues Page. For best results:

  • 🧪 Include a reproducible example using simulated data if needed.
  • 💻 Share your code snippet that causes the issue.
  • 📝 Explain what you expected vs what actually happened.
  • 📦 Mention your R and INLA versions using R.version and packageVersion("INLA").

4. Check the INLA Issue Tracker

Before creating a new issue, browse the INLA Issue Tracker. Issues are categorized with helpful labels like:

🐛 bug – unexpected behavior or crashes
⚙️ installation – setup or update issues
✨ enhancement – new feature requests
📚 documentation – unclear or missing help
🔁 duplicate – already reported
🚫 ntfixed – known but not fixed
🧐 not reproducible / unclear – unable to verify or missing details
🧭 new inla users – first-time user questions

5. Still Need Assistance?

Contact us via help@r-inla.org for private issues.
